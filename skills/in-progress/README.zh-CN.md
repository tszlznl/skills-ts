# In Progress（开发中）

仍在开发中的技能（skills）。它们还不适合发布——会有粗糙边角、破坏性变更（breaking changes），也可能是被放弃的实验。它们在“毕业”进入稳定桶（stable bucket）前，会被排除在插件（plugin）与顶层 README 之外。

- **[review](./review/SKILL.zh-CN.md)** — 以两个平行维度评审从某个固定点以来的变更：**标准（Standards）**（diff 是否符合仓库编码规范？）与 **规格（Spec）**（diff 是否忠实实现了来源 issue/PRD？）。
- **[writing-beats](./writing-beats/SKILL.zh-CN.md)** — 把文章塑造成一段段“节拍（beats）”的旅程，类似选择你自己的冒险（choose-your-own-adventure）。先选一个起始节拍，只写这一段，然后转向下一段，直到文章自然结束。
- **[writing-fragments](./writing-fragments/SKILL.zh-CN.md)** — 拷问式沟通（grilling session），从你那里挖出“碎片（fragments）”——各种形态的写作小块——并把它们作为未来文章的原材料，追加到同一个文档中。
- **[writing-shape](./writing-shape/SKILL.zh-CN.md)** — 将一份作为原材料的 Markdown 文件逐段塑形为文章，并在每一步为格式选择（format choices）进行论证。
