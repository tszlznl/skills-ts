# Productivity（效率）

通用工作流工具，不局限于代码。

- **[caveman](./caveman/SKILL.zh-CN.md)** — 超压缩沟通模式。通过删掉填充语（filler）来减少约 75% 的 token 消耗，同时保持完整技术准确性（technical accuracy）。
- **[grill-me](./grill-me/SKILL.zh-CN.md)** — 围绕你的计划或设计进行高强度访谈（interview），直到决策树（decision tree）的每个分支都被明确。
- **[handoff](./handoff/SKILL.zh-CN.md)** — 把当前对话压缩成一份交接文档（handoff document），便于另一个智能体继续工作。
- **[write-a-skill](./write-a-skill/SKILL.zh-CN.md)** — 用正确结构、渐进式披露（progressive disclosure）与捆绑资源（bundled resources）创建新技能。
