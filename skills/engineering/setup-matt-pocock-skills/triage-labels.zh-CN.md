# 分诊标签（Triage Labels）

这些技能（skills）使用 5 个规范分诊角色（canonical triage roles）进行沟通。该文件把这些角色映射到你们的问题跟踪器（issue tracker）里实际使用的 label 字符串。

| mattpocock/skills 中的 label | 我们问题跟踪器中的 label | 含义（Meaning）                         |
| ---------------------------- | ------------------------ | -------------------------------------- |
| `needs-triage`               | `needs-triage`           | 维护者需要评估该 issue                 |
| `needs-info`                 | `needs-info`             | 等待报告者补充更多信息                 |
| `ready-for-agent`            | `ready-for-agent`        | 规格完整，适合交给 AFK（Away From Keyboard）智能体 |
| `ready-for-human`            | `ready-for-human`        | 需要人类实现                           |
| `wontfix`                    | `wontfix`                | 不会处理                               |

当某个技能提到一个角色（例如“应用 AFK-ready 的分诊标签”），请使用表中对应的 label 字符串。

把右侧列编辑成你们真实使用的词汇。
